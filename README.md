# Freiman Dev

Landing page desenvolvida com Next.js, TypeScript e Tailwind CSS. O projeto usa o App Router, renderização estática, imagens otimizadas e metadados de SEO.

## Run Locally

**Pré-requisito:** Node.js 20.9 ou superior.


1. Instale as dependências:
   `npm install`
2. Opcionalmente, defina a URL pública em `.env.local`:
   `NEXT_PUBLIC_SITE_URL=https://seudominio.com.br`
3. Inicie o ambiente de desenvolvimento:
   `npm run dev`

Para validar a versão de produção:

`npm run build`
